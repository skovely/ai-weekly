3.1 供需缺口

AI 模型评估与智能体基准测试平台

需求证据： IBM 发布 Open Agent Leaderboard，Kimi K2.6 登顶 Finance Agent V2 基准。企业对「哪个模型适合我的 Agent 场景」的标准化评估需求明确。
供给现状： 已有分散的 leaderboard，但缺乏一站式入口。
Watcha 佐证： 灵光（🔥92）、Alice（🔥28）、蚂蚁阿福（🔥29）高热 → 用户对「选哪个 AI」有明确需求。
🟣 Follow Builders 佐证： @trq212 推文「as much as you spec there are always still ambiguities and unknown unknowns that come up」（❤353）直接指向 Agent 场景下模型选择的实际痛点。这不是市场研究报告的推测，而是一线 Builder 的实战反馈。

Agent 编排与规范工程工具

需求证据： 本周 Follow Builders 的最大信号——@trq212 的「Agent 规范写作」长篇走红（❤1,051），@levie（Box CEO）称「probably the biggest challenge that most companies run into in their agent strategy is getting agents the right constrained context to work with」（❤132），@rauchg 发布 Agent Firewall（❤303）。

影响方向： 可能触发 AI 编程、Agent 平台新一轮竞争升级。
